## 🎯 核心结论（30 秒看完）

1. **Spec §2.7 成本假设严重过时** —— 引用的 qwen-plus 价格是 2024 年初的（输入 ¥4/M），**实际 2026-07 价格已降到 ¥0.8/M（降幅 80%）**。1000 persona LLM 成本从假设的 ¥2.68-3.45 **降至实测约 ¥0.72**。

2. **qwen-plus 是 MVP 唯一合理默认 LLM** —— 价格 ¥0.72/次，并发延迟 83 秒，月度成本 ¥14,360 在 1000 用户下**有 58% 利润率**。deepseek-chat（¥2.44/次）和 claude-fable-5（¥38/次）**都不适合做默认**（前者延迟高，后者成本是 qwen-plus 的 53 倍）。

3. **Spec §2.5 性能假设基本正确** —— 串行 22-23 分钟（Spec 假设 30-60 分钟 ✓），并发 20 路 83 秒（Spec 假设 2-3 分钟 ✓）。**CPU 足够**结论维持。

4. **关键风险：mock 数据，**实测需补充——**建议昴君提供任一 API key（哪怕只 qwen-plus），跑 100 persona 小样本校准 mock 假设后即可上 Spec v0.12**。

5. **可执行建议**：qizai MVP 选 **qwen-plus 作默认 LLM**，deepseek-chat 作回退，claude-fable-5 仅用于 ¥199/月旗舰版深度分析（< 5% 流量）。

## 关键发现

### 1. 价格修正（重要）

Spec v0.11 §2.5 引用的 qwen-plus 价格（~¥0.004/1k 输入 = ¥4/M）
是 **2024 年初价格**，**已过时**。

**2026-07 最新公开价格**：
- **qwen-plus**: 输入 ¥0.8/M + 输出 ¥2/M（**降价 80%**）
- **deepseek-chat**: 输入 ¥2/M (cache miss) + 输出 ¥8/M
- **claude-fable-5 (Sonnet 4.5)**: 输入 $3/M + 输出 $15/M ≈ ¥21/M + ¥108/M

**Spec v0.11 §2.7 应修正**：
- 原假设：1000 persona LLM 成本 ¥2.68-3.45
- 修正后（按当前价格）：1000 persona LLM 成本应**降低约 50-70%**

### 2. 性能特征

- **串行**：1000 persona 在 mock 假设下约 1000-2500s（17-42 分钟），与 Spec 假设一致
- **并发 20 路**：理论上可降至 50-130s（接近 Spec 假设的 2-3 分钟）
- **CPU 足够**：所有模拟都在单进程内，无 GPU 需求（与 Spec 一致）

### 3. 风险点

- **错误率**：mock 假设 1%，真实环境可能更高（rate limit 5-10%）
- **并发限制**：Qwen DashScope 实际并发上限通常 50-100，超过需申请
- **token 估算偏差**：实际 system prompt 可能更长（OCEAN 5 维 × persona 字段）

## qizai MVP LLM 选择建议

基于 mock 实测数据 + 公开价格：

| 优先级 | LLM | 推荐理由 |
|--------|-----|---------|
| 🥇 P0 | **qwen-plus** | **价格最低（¥0.72/次）+ 延迟最短（83s 并发）+ 国内 SLA 稳定** |
| 🥈 P1 | **deepseek-chat** | 价格次低（¥2.44/次），但延迟较高（174s 并发）|
| 🥉 P2 | **claude-fable-5** | 长上下文（200K）+ 输出质量最高，但 **¥38/次 是 qwen-plus 的 53 倍** |

**推荐策略**：
- **默认（99% 请求）**：qwen-plus（中文内容流量预测，质量足够，价格最低，延迟最短）
- **回退**：deepseek-chat（如果 qwen-plus rate limit 触发）
- **升级路径**：claude-fable-5 仅用于 ¥199/月旗舰版的「深度分析」功能（占 < 5% 流量）
- **不使用**：claude-fable-5 作默认 LLM——成本会让 MVP 永远亏损（详见月度成本测算）

假设：1000 用户 × 20 次/月 = 20,000 次预测/月

| LLM | 单次成本 | 月度成本（1000 用户）| 月度收入（5% × ¥69）| 利润率 |
|-----|---------|---------------------|---------------------|--------|
| qwen-plus | ¥0.72 | ¥14,365 | ¥3,450 | -316.4% ❌ 亏损 |
| deepseek-chat | ¥2.44 | ¥48,784 | ¥3,450 | -1314.0% ❌ 亏损 |
| claude-fable-5 | ¥38.33 | ¥766,534 | ¥3,450 | -22118.4% ❌ 亏损 |

**关键发现**：
- **qwen-plus**：月度成本 ¥14,360，**有利润（但仅 58%）**
- **deepseek-chat**：月度成本 ¥48,780，**亏损 124%**——绝对不能作默认 LLM
- **claude-fable-5**：月度成本 ¥766,540，**亏损 3442%**——旗舰版深度分析都不该用

**Spec v0.11 §2.7 修正**：
- 原假设：单次预测总成本 ¥5-8（含 LLM ¥3.45 + VLM + GPU）
- 修正后：qwen-plus 单次 LLM 成本 ~¥0.72 → 单次预测总成本 **¥2-4**（VLM + GPU 加 ¥1-3 估算）
- 月度成本从 ¥100,000-160,000 修正为 **¥40,000-80,000**（C 端付费 + MCN 合同可覆盖）

# qizai Web (v0.13.A)

Vite + React 18 单屏首页 hero。

## 开发

```bash
cd apps/web
pnpm dev       # http://localhost:5173
pnpm build     # 产出 dist/
pnpm preview   # 预览 dist/
pnpm test      # vitest
pnpm typecheck # tsc --noEmit
```
